# NULL//SIGNAL

Хакерский лаунчер для Android в стиле терминала: рабочий стол, сюжет про подпольную группу
и **настоящие** сетевые инструменты, которые работают с твоими собственными устройствами и эфиром вокруг.

## Что внутри

| Модуль | Что делает по-настоящему |
|---|---|
| **TERMINAL** | `ping`, `traceroute`, `dig`, `whois`, `ssl`, `sechead`, `curl`, `nc`, `myip`, `wifiinfo`, `portscan` (своя сеть), Linux-шелл `sh …`, `sysinfo`, `hash`, `b64`, `hex`, `caesar`, `rot13`, `jwt`, `encrypt`/`decrypt`, `pwcheck`, `urlcheck`, `passgen`, `matrix`, запуск приложений `run <имя>` |
| **NETSCAN** | Находит устройства в твоей Wi-Fi сети, их открытые порты, имена и mDNS-сервисы (ТВ, колонки, принтеры). Предупреждает об открытых ADB и telnet |
| **WIFI-RADAR** | Сети вокруг: сила сигнала, канал, диапазон, тип защиты. Открытые сети и WEP подсвечиваются |
| **BLE-RADAR** | Анимированный радар Bluetooth LE устройств с примерной дистанцией |
| **MONITOR** | Скорость загрузки/отдачи и пинг до роутера и интернета в реальном времени, с графиками |
| **AUDIT** | Аудит безопасности телефона: блокировка, шифрование, ADB, патчи, root — оценка 0–100 и советы. Какие приложения имеют доступ к камере, микрофону, SMS |
| **TOOLS** | Проверка надёжности пароля, генератор, шифрование заметок AES-256, QR-генератор и сканер с проверкой ссылки, анти-фишинг |
| **GAMES** | BREACH (подбор ключа), ШИФРЫ (9 перехватов), КОД (найди уязвимость), УЗЛЫ (собери сеть) |
| **ACADEMY** | Курс Python для хакеров из 9 уроков с заданиями: от `print` до собственного порт-сканера |
| **MESSAGES** | Сюжетный канал группы NULL//SIGNAL: задания открываются по мере прохождения |

Сканер сети работает **только в частных сетях** (192.168.x.x, 10.x.x.x, 172.16–31.x.x) и только в той,
к которой подключён телефон. Радары пассивные: только слушают эфир, ничего не отправляют чужим устройствам.

Сканируй только свою сеть или сеть, где у тебя есть разрешение владельца.

## Установка

APK собирается автоматически при каждом пуше в `main`: смотри раздел **Releases** справа на странице репозитория.
После установки: «сделать NULL//SIGNAL рабочим столом» внизу главного экрана.

## Сборка

```
./gradlew :core:test          # логика (сюжет, терминал, взлом, сети) — без Android SDK
./gradlew :app:assembleDebug  # APK — нужен Android SDK
```

`core/` — чистый Kotlin (тестируется на JVM), `app/` — Android + Jetpack Compose.

Все персонажи, группировка и корпорация Helix Data вымышлены.
