# NULL//SIGNAL

Хакерский лаунчер для Android: строгий тёмный интерфейс, сюжет про подпольную группу
и **настоящие** инструменты, которые работают с твоим телефоном, твоей сетью и открытыми данными.
Без root.

## Модули

### Слежка и защита
| Модуль | Что делает |
|---|---|
| **ПЕРЕХВАТ** | DNS-перехватчик и файрвол на VpnService: какое приложение к какому домену обращается в реальном времени, распознавание трекеров, блок-листы (StevenBlack, AdAway, OISD, HaGeZi, RU AdList), свои правила и исключения, «отрезать приложение от сети», DNS-over-HTTPS, топ доменов, экспорт CSV |
| **АНТИСЛЕЖКА** | Метки слежения рядом (AirTag/Локатор, SmartTag, Tile) с таймером «следует за тобой»; шпионские программы: скрытые приложения с опасными доступами, спец. возможности, слушатели уведомлений, администраторы устройства |
| **РЕНТГЕН** | Трекеры, вшитые в APK каждого приложения (разбор DEX по методике Exodus Privacy, 65 SDK): реклама, аналитика, продажа геолокации, запись экрана |
| **СЛЕДЫ** | Когда телефон разблокировали и какие приложения открывали — в том числе ночью и без тебя |
| **УВЕДОМЛЕНИЯ** | Журнал всех уведомлений и сообщений, включая удалённые отправителем |
| **КАМЕРЫ** | Поиск IP-камер в сети: RTSP, ONVIF WS-Discovery, порты Dahua/Hikvision/XMEye, веб-интерфейсы |
| **ПРОСЛУШКА?** | Перехватывают ли твой трафик: чужие корневые сертификаты, прокси, VPN, подмена DNS-ответов, вставки в страницы, подменённые HTTPS-сертификаты, открытый Wi-Fi; кто прямо сейчас пишет микрофон или держит камеру |
| **ПРОВЕРКА ФАЙЛА** | Что за файл на самом деле: тип по содержимому, а не по расширению; двойные расширения и подмена имени; макросы в документах, скрипты в PDF; что лежит в архиве; разрешения и подпись APK до установки; отпечатки MD5/SHA и адреса внутри файла. Файл не запускается и никуда не отправляется |
| **АУДИТ** | Оценка защищённости телефона 0–100 и доступы приложений к камере, микрофону, SMS |

## Правила

Сканеры сети работают **только в частных сетях** и только в той, к которой подключён телефон.
Радары, СОТЫ и СПУТНИКИ пассивные — только слушают эфир. OSINT — только открытые публичные источники.
Проверяй свои устройства и свою сеть или там, где есть разрешение владельца.

## Установка

APK собирается при каждом пуше в `main`: раздел **Releases** справа на странице репозитория.

## Сборка

```
./gradlew :core:test          # вся логика: 130+ тестов (интерпретатор Python, протоколы, крипто, сюжет) — без Android SDK
./gradlew :app:assembleDebug  # APK — нужен Android SDK
```

`core/` — чистый Kotlin с тестами на JVM, `app/` — Android + Jetpack Compose.

Все персонажи, группировка и корпорация Helix Data вымышлены.
