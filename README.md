# NULL//SIGNAL

Хакерский лаунчер для Android: строгий тёмный интерфейс, сюжет про подпольную группу
и **настоящие** инструменты, которые работают с твоим телефоном, твоей сетью и открытыми данными.
Без root.

## Модули

### Слежка и защита
| Модуль | Что делает |
|---|---|
| **ПЕРЕХВАТ** | DNS-перехватчик и файрвол на VpnService: какое приложение к какому домену обращается в реальном времени, распознавание трекеров, блок-листы (StevenBlack, AdAway, OISD, HaGeZi, RU AdList), свои правила и исключения, «отрезать приложение от сети», DNS-over-HTTPS, топ доменов, экспорт CSV |
| **АНТИСЛЕЖКА** | Метки слежения рядом (AirTag/Локатор, SmartTag, Tile) с таймером «следует за тобой»; шпионские программы: скрытые приложения с опасными доступами, спец. возможности, слушатели уведомлений, администраторы устройства |
| **РЕНТГЕН** | Трекеры, вшитые в APK каждого приложения (разбор DEX по методике Exodus Privacy, 65 SDK): реклама, аналитика, продажа геолокации, запись экрана |
| **СЛЕДЫ** | Когда телефон разблокировали и какие приложения открывали — в том числе ночью и без тебя |
| **УВЕДОМЛЕНИЯ** | Журнал всех уведомлений и сообщений, включая удалённые отправителем |
| **КАМЕРЫ** | Поиск IP-камер в сети: RTSP, ONVIF WS-Discovery, порты Dahua/Hikvision/XMEye, веб-интерфейсы |
| **АУДИТ** | Оценка защищённости телефона 0–100 и доступы приложений к камере, микрофону, SMS |

### Сеть
| Модуль | Что делает |
|---|---|
| **СКАН СЕТИ** | Устройства в своём Wi-Fi: тип, имя (UPnP, NetBIOS, веб-интерфейс), MAC Windows-машин, открытые порты с советами, тревога о новых устройствах; аудит роутера (проброшенные через UPnP порты, внешний IP, что видит Shodan); Wake-on-LAN |
| **МОНИТОР** | Скорость и пинг до роутера и интернета с графиками |
| **СПИДТЕСТ** | Пинг, джиттер, загрузка и отдача через Cloudflare, история |
| **ТЕРМИНАЛ** | 80+ команд: `ping`, `traceroute`, `dig`, `whois`, `ssl`, `sechead`, `curl`, `nc`, `portscan`, `upnp`, `wol`, `ipinfo`, `subdomains`, `tech`, `mailsec`, `wayback`, `user`, `leak`, `pwned`, `calc`, `base`, `subnet`, `json`, `totp`, `morse`, шифры, Linux-шелл `sh` |
| **SSH** | SSH-клиент: пароль или ключ RSA (создаётся в приложении), проверка отпечатка сервера, Termux на этом же телефоне |

### Разведка
| Модуль | Что делает |
|---|---|
| **OSINT** | Ник на 29 сайтах; почта по базам утечек; IP — геолокация, провайдер, открытые порты и CVE (Shodan InternetDB); домен — DNS, WHOIS, SPF/DMARC (можно ли подделать письмо), технологии сайта, поддомены из crt.sh, веб-архив |
| **EXIF** | Где и на что снято фото (GPS, модель, серийник), чистая копия без метаданных |

### Эфир и железо
| Модуль | Что делает |
|---|---|
| **WIFI-РАДАР** | Сети вокруг, защита, WPS; загрузка каналов и лучший канал для своего роутера |
| **BLE-РАДАР** | Радар Bluetooth-устройств с производителем и примерной дистанцией |
| **NFC** | UID и тип чипа, содержимое меток; запись ссылки или текста |
| **ИК-ПУЛЬТ** | Пульт для ТВ Samsung, LG, Sony, Philips, Toshiba и перебор кодов питания |
| **ДАТЧИКИ** | Металлоискатель на магнитометре, компас и уровень, все датчики телефона |

### Крипто и шпионаж
| Модуль | Что делает |
|---|---|
| **ШПИОНАЖ** | Текст внутри картинки (стеганография + AES), невидимые чернила в тексте, шифрование любых файлов AES-256-GCM, хеши, азбука Морзе фонариком/звуком/вибрацией |
| **2FA** | Одноразовые коды TOTP как в Google Authenticator, импорт по QR |
| **ИНСТРУМЕНТЫ** | Надёжность пароля и проверка по утечкам, генератор, шифрование заметок, QR, анти-фишинг |

### Группа
Сюжетный канал, тренажёры (взлом, шифры, поиск уязвимостей в коде, узлы) и курс Python из 9 уроков.

## Правила

Сканеры сети работают **только в частных сетях** и только в той, к которой подключён телефон.
Радары пассивные. OSINT — только открытые публичные источники.
Проверяй свои устройства и свою сеть или там, где есть разрешение владельца.

## Установка

APK собирается при каждом пуше в `main`: раздел **Releases** справа на странице репозитория.

## Сборка

```
./gradlew :core:test          # вся логика (протоколы, крипто, OSINT, сюжет) — без Android SDK
./gradlew :app:assembleDebug  # APK — нужен Android SDK
```

`core/` — чистый Kotlin с тестами на JVM, `app/` — Android + Jetpack Compose.

Все персонажи, группировка и корпорация Helix Data вымышлены.
